# Public release safety checklist

This entire package is a fictional, separately authored demonstration. It does not ship workplace source files or the source Skill. The original material was used **only to understand high-level process patterns**.

- [x] Synthetic vendor names (`Demo Vendor ...`) and invented invoice references (`DEMO-...`).
- [x] Fictional ledger accounts (`61110`, `61120`, `13880`), cost center labels and projects.
- [x] No workplace client, broker or employee names.
- [x] No original organizational accounting dimensions or source file paths.
- [x] No original approval journal, Finance extract, financial numbers or screenshot.
- [x] All mock transactions constructed for test cases and explicitly labeled synthetic.
- [x] New public Skill instructions authored for the demo; the original Skill is not copied.
- [x] New sample engine code, which is expressly not presented as the original internal tool.
- [x] No passwords, tokens, contact information, personally identifiable records or financial account IDs.
- [ ] Human final review of files AND repository history before publishing.
- [ ] Confirm employer IP / confidentiality / portfolio rights are respected.

**Do not include** the separate private source dossier in the GitHub repository or in any public release archive.

Avoid copying sample workplace data, even if anonymized. Generate fictional data instead, because real invoice combinations and amounts can be identifiable through relationships.
